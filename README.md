# 六级全科60天训练器

面向四级约480分、听力、写译与选词填空薄弱的学生。纯HTML/CSS/JavaScript，无需安装依赖或填写API密钥，可在手机浏览器使用。

## 使用

1. 打开网页，阅读“使用说明”，准备自己合法获取的六级真题、音频和答案。
2. 按“今日训练”练习；写作与翻译可进入“写译课堂”。
3. 在“训练复盘”填写各题型首次成绩、用时、错因，以及明天可用时间、疲劳、睡眠和遮答案回测情况。
4. 点击“判断强度，生成明日计划”。软件安排材料范围、步骤、完成标准、休息和训练时间。
5. 打开下一日任务，执行与打卡。每周查看成长记录的变化。

## 功能与边界

- 60天分阶段路线，覆盖听力、选词、匹配、仔细阅读、写作和翻译。
- 写作与翻译各7节方法课，包含示范、练习、自查和草稿保存。
- 根据成绩、错因与自报状态生成下一日任务；睡眠或掌握情况缺失时，不自动批准加量。
- 近7训练日与上周期趋势对比：每周期每题型至少两次记录才比较，写译自查错误数仅作个人辅助指标。
- 典型错题在第1、3、7训练日后进入回测清单，未完成的继续保留；明日计划为到期回测预留时间。
- 学习建议由透明规则生成，不接入AI接口，不自动给作文、译文打官方分数。
- 使用训练日Day 1—60，不等于真实日历日期。漏学后继续当前训练日，不堆积任务。
- 数据保存在当前浏览器localStorage；不同设备不会自动同步，清理浏览器数据可能删除记录。
- 不上传学习记录、草稿，不提供用户账号或后台数据库。

## 本地运行

双击 `index.html`，或在本目录运行 `python -m http.server 8000` 后打开 `http://localhost:8000`。发布版与本地版的浏览器记录分开保存。

## 发布到 GitHub Pages

将本目录中的文件上传到一个公开仓库，在 **Settings → Pages → Build and deployment** 选择 **Deploy from a branch**，分支 `main`，目录 `/ (root)`，保存。等待部署完成后，打开设置页提供的实际网址。

手机打开网址后，可用浏览器的“添加到主屏幕”功能保存入口。页面需要联网加载，并不提供离线缓存保证。
